This page is a glossary of all of the crazy terms we come up with in IT. Even veterans sometimes come up against terms we don't recognise, especially if they're outside of our tech silo!

## Compute

- [Nanolab](/start-here/nanolab/) - See [Nanolab](/start-here/nanolab/)
- TDP - Thermal Design Power

## Networking

- BMC - Baseboard Management Controller
- IPMI - IP Management Interface
- iLO - Integrated Lights Out (HP Specific IPMI)
- iDRAC - Integrated Dell Remote Access Controller (Dell Specific IPMI)
- DAC - Direct Attached Cable
- NIC - Network Interface Controller
- SFP - Small Form-factor Pluggable, max 4.25Gbps
- SFP+ - Small Form-factor Pluggable+, max 10Gbps
- PoE - Power Over Ethernet, 802.3af max 15.4 watts
- PoE+ - Power Over Ethernet+, 802.3at max 25.5 watts

## Storage

- DWPD - Drive Writes Per Day
- HDD - Hard Disk Drive
- IOPS -Input/Output Operations per Second
- NAS - Network Attached Storage
- NTFS - NT File System
- PATA - Parallel ATA
- RAID - Redundant Array of Independent Disks
- SAN - Storage Area Network
- SAS - Serial Attached SCSI
- SATA - Serial ATA
- SMART - Self-Monitoring, Analysis and Reporting Technology
- SSD - Solid State Drive
- TBW - Terabytes Written
- BTRFS - B-Tree File System
- ZFS - Zettabyte File System

## Design

- MTBF - Mean Time Between Failures
- MTTR - Mean Time To Recover
- RPO - Recovery Point Objective
- RTO - Recovery Time Objective
